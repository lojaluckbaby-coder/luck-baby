LUCK BABY — BANCO CENTRAL E FOTOS

Esta versão deixa de depender apenas do localStorage para produtos, banners, marcas e configurações públicas.

1) No Cloudflare, abra o projeto Pages/Workers do luck-baby.
2) Crie um banco D1 chamado: luck-baby-db.
3) Execute o arquivo schema.sql no D1.
4) Crie um bucket R2 chamado: luck-baby-images.
5) Ligue os bindings ao projeto:
   D1: variável DB
   R2: variável BUCKET
6) Crie uma variável/secret de produção:
   ADMIN_PASSWORD = 251400
7) Publique esta pasta por Git/Wrangler. Pages Functions precisam ser implantadas com Functions; o upload direto de arquivos no painel não suporta Functions.

Depois de publicado:
- Clientes usam GET /api/store e recebem produtos, banners, marcas e configurações públicas.
- O painel envia alterações para POST /api/store usando a senha.
- Fotos são enviadas para R2 por /api/upload e servidas por /api/image/...

IMPORTANTE: a senha fica no servidor como secret. Não dependa de senha escrita no JavaScript para proteger o banco.
